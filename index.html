Hi, I'm Sourabh 👋

I'm Sourabh Singh, a B.Tech CSE student at JECRC University specializing in AI, DevOps & Cloud Automation. I build complete web applications from scratch — from an AI assistant wired to real Gemini models to a full food-delivery platform with live maps — using nothing but HTML, CSS and JavaScript.

How I built these 💡

Every project here is a single HTML file — no frameworks, no build tools, no copied templates. That constraint forced me to understand exactly how the browser works: layout, events, state, and the DOM.

The AI assistants taught me asynchronous programming and API integration; the food platform taught me complex application state — carts, filters, maps and checkout flows all talking to each other.

How each project came to life

A short walkthrough of the process — useful context when presenting to a class.

1

Learning the fundamentals

foundation

Started with plain HTML & CSS — no shortcuts. Built static pages first, then made them respond to users with JavaScript.

2

Sense v1 — first real app

first assistant

Designed a complete assistant interface: sidebar, chat area, states. Learned CSS Grid, theming with variables, and component thinking.

3

Real AI — Sense v3

the breakthrough

Connected the UI to a real AI model running client-side. Learned async/await, streaming responses, and handling API failures gracefully.

4

FOODORA — complex state

biggest challenge

48 dishes, 12 restaurants, a live map, GPS, a cart, checkout, and multilingual recipes — all synchronized in one page. Learned to manage application state carefully.
