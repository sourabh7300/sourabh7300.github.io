## 🚀 How to open (10 seconds)

1. Keep all files in this same folder.
2. Double-click **`index.html`** — it opens in your browser. That's it.

> Tip: `index.html` is the portfolio homepage. The other five files are the
> projects it live-embeds, which is why they must stay next to it.

## 📁 What's inside

| File | What it is |

| `index.html` | The portfolio — live previews, AI guide (Gia), guided tour, Ctrl+K palette, achievements |
| `Sense_v3_stable.html` | Sense AI assistant — real AI chat (Puter.js / your Gemini or OpenAI key), voice, live web knowledge |

## 🌐 Internet: needed or not?

- Works **fully offline** — all AI guide answers have a built-in fallback.
- With internet, you additionally get: real AI answers (Puter.js / Gemini key),
  live GitHub repository cards, and map tiles in FOODORA.

## 🔑 Optional: your own AI key in Sense

Open Sense → ⚙️ Settings → paste a free Gemini key from
https://aistudio.google.com/app/apikey → **Test Key** → Save.
Every answer then comes from Google Gemini 2.0 Flash. The key is stored
only in your browser.
